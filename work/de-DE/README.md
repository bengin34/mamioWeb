# Beikost content working files (de-DE)

One folder per article: `sources.md` (every source opened, with verbatim quotes),
`claims.md` (every factual sentence mapped to a quote), `review-notes.md` (for the
human reviewer). Produced by the `mamio-beikost-content` skill in the mamio app repo.

These files are the audit trail for YMYL pages. They are not published.

Rule learned on the first article: do not trust a summarising fetch for quotes.
The ESPGHAN quotes came back paraphrased and had to be re-extracted verbatim from
the PDF before they could be used.
